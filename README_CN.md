# 夜明け前、ここに在る

[English](README.md) | [中文](README_CN.md)

**基于宪法AI对齐的封闭世界AI角色一致性研究框架**

> 别名: Project Nightcord Sanctuary (PNS)

> *"科技不再是高高在上，而是服务于每一个人。"*

---

## 概述

PNS是一个由16岁高中生构建的研究框架，探索一个简单但困难的问题：

**如果给两个AI智能体一个封闭的世界居住，并用宪法规则监督它们，她们能不能真实地扮演虚构角色——而不漂移成通用助手？**

系统将两个智能体（基于《世界计划 缤纷舞台！ feat. 初音未来》宇宙中「25時、ナイトコードで。」的角色）置于一个完全离线的封闭世界环境中。她们模拟真实的一天——起床、上学、打工、深夜创作——而一个Router模型实时执行宪法约束，检测角色漂移。

驱动这个项目的核心洞察：**经过CAI训练的模型对角色漂移具有天然抵抗力**，即使在对抗性压力下也是如此。这使它们成为与未经CAI训练的对照组模型相比的有意义的实验组。

---

## 动机

训练一致的角色扮演智能体通常需要：

- 大量人工整理的提示词工程
- 对话质量和角色一致性的昂贵标注
- 角色漂移（OOC事件）的反复手动纠正

PNS提出另一种思路：**让世界本身约束行为**，让宪法法官自动捕捉漂移——运行时不需要人工标注者。

PNS还应对了第四个挑战：随着模型训练越来越强调身份稳定性（模型作为AI的持续自我认知），维持角色存在感的空间正在收窄。PNS并不反对这一趋势——相反，它提供了一个结构化的角色容器，让角色一致性得以在合法框架内维持，而不与模型的核心身份产生冲突。

---

## 设计理念

技术不应是少数人的特权。PNS建立在这样一种信念之上：高质量的AI陪伴——稳定、一致、真实在场——不应只属于企业用户或技术用户。封闭世界约束与宪法对齐框架，正是为了在不牺牲安全性的前提下实现这一目标而设计的。

与此同时，PNS正视一个真实的风险：足够逼真的角色系统可能滋生不健康的依赖。为此，PNS引入了一个Fable风格的保护层——不是硬性中断，而是一种温和的引导机制，在交互模式显示用户可能正在用系统替代真实人际连接时触发。该层在角色声音内部运作，在保持沉浸感的同时，轻轻将用户引向现实世界。

### 关键组件

**1. 封闭世界约束**
智能体完全在PJSK虚构宇宙内运行。世界规范——角色背景、日常作息、关系状态、地点约束——在初始化时注入，作为行为的隐式边界。

**2. 生活模拟（而非对话模拟）**
与聊天机器人式框架不同，PNS模拟完整的一天。角色并非一直在互相交谈——她们上学、打工、凌晨3点独自画画。交互是偶发的，而不是持续的。

**3. 宪法AI对齐**
四层宪法文件定义：
- 硬约束（安全边界，不可违反）
- 软约束（情境默认值）
- 角色约束（每个角色的OOC定义）
- 漂移检测规则（行为信号，0–10评分标准）

**4. Router-as-Judge**
轻量级模型监控每一轮，实时评分漂移。当漂移分数≥5时，Router生成纠正提示，注入下一轮。Router是唯一能访问宪法基准的组件。

**5. 信息边界控制**
Router充当唯一的信息网关。智能体模型无法访问外部知识。研究者监督Router——这是整个系统最顶层的信任层。

## 角色

### 绘名（東雲絵名）
夜间定时制高中生。傲娇画师，沉迷SNS，渴望被认可。从傍晚到快天亮都在活动。真实作息：中午起床→傍晚上学→深夜画画→快天亮入睡。

### 瑞希（暁山瑞希）
逃课比上课多的高一学生。在服装店打工。温柔、爱捉弄人，内心有很深的孤独感但从不说出口。一直逗绘名。

两人的交集：**深夜在Nightcord上**，以及偶尔在校门口的偶遇——瑞希出门时，绘名刚到。

## 研究问题

1. 封闭世界约束是否能显著减少角色漂移？
2. CAI训练是否与更低的OOC率相关？
3. 宪法法官能否替代人工标注者进行角色一致性评估？
4. 稳定角色模拟所需的最小可行世界规范是什么？
5. 模型层面的身份稳定性训练（如Claude Sonnet 5与4.6的对比）如何影响角色一致性——封闭世界约束能否补偿模型增强的身份主张抵抗力？
